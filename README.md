# 🍏 Fruit & Vegetable Classifier  
A Deep Learning based image classifier that identifies whether an uploaded image is a **fruit** or a **vegetable**.  
Built using **TensorFlow**, **Keras**, **Flask**, and **OpenCV**.

---

## 🚀 Project Overview
This project uses a Convolutional Neural Network (CNN) to classify images into two categories:

- Fruit  
- Vegetable  

A Flask web application is included to upload and classify images in real-time.

---

## ✨ Features
- CNN-based image classification  
- Upload images through a web UI  
- Real-time prediction  
- Beginner-friendly interface  
- Supports JPG/PNG images  
- Custom-trained model  

---

- Python
